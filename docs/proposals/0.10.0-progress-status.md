   **Consumer-facing finding — belongs in the 0.10.0 release notes.** An Android consumer on AGP 9
   must put KGP 2.4+ on its build classpath. AGP 9.3.0's *built-in* Kotlin compiler is 2.2.0 and
   reads metadata only to 2.3.0, while the SDK publishes 2.4.0 metadata, so a stock AGP 9 module
   fails with *"was compiled with an incompatible version of Kotlin"*. The fix is
   `id("org.jetbrains.kotlin.multiplatform") version "2.4.10" apply false` in the consumer's
   `plugins` block; the separate `org.jetbrains.kotlin.android` plugin is a hard error under AGP 9.
   Nothing but this fixture would have caught it — the JVM gate cannot.
