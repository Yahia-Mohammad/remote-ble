## Review status

Two review passes are fully addressed. The first (`origin/main → a182f35` plus follow-up working-tree
corrections) cleared the mobile-bind regression, principal logging, Rust framing-layer limit,
limit-error classification, per-frame Kotlin double decode, radio-grace wording, and the protocol
terminal-state, Hello-validation, duplicate-session, management-read, and resource-invariant blockers
— all with regressions in both agents. The second focused review (2026-07-16) raised four items — the
late-connect lease guard, operator-auth rate limiting, MTU argument validation, and duplicate-session
documentation — now all resolved (final *Implemented* row).
